Cubi, l'IA locale de Logical

Un modèle de langage qui tourne dans le navigateur (WebGPU), sans serveur ni compte. Une page l'intègre en une ligne, puis lui confie des petites tâches : répondre, corriger, reformuler. On suit ce qu'il fait et sa réflexion au fil de l'eau.

<script type="module">
import { connect } from "https://ggoutard.github.io/Web-Agentic-Model/sdk/cubi.js";

const cubi = connect();                     // mode léger : rien d'affiché
cubi.on("state", (s) => console.log(s.phase, s.progress));

const { text } = await cubi.ask("Résume ce texte", {
    document: document.body.innerText,      // il lit tout
    onStep: (s) => console.log(s),          // ce qu'il fait
    onThought: (t) => console.log(t),       // sa réflexion
    onText: (t) => console.log(t),          // sa réponse, au fil de l'eau
});
</script>

Avec le personnage : connect({ ui: true, container }) (pages du même site seulement).
